# 🧩 VIBE TAXONOMY STUDIO (v1.0)

[![GitHub Pages](https://img.shields.io/badge/GitHub%20Pages-Live%20v1.0-blue?logo=github)](https://tmin2.github.io/vibe-taxonomy-studio/)
[![Release](https://img.shields.io/badge/Release-v1.0-emerald.svg)](https://github.com/tmin2/vibe-taxonomy-studio/releases)

바이브 디자인 텍소노미 인터랙티브 스튜디오 (Vibe Taxonomy Studio) v1.0 공식 릴리즈입니다.

- **UI 컴포넌트 전수**: 165종 전수 렌더링 & 원클릭 토큰 바구니 복사
- **AI & 물리 모션 피직스**: 38종 인터랙티브 라이브 애니메이션 (스켈레톤 쉬머, 다이내믹 아일랜드, 스프링 모핑 등)
- **글로벌 디자인 사조**: 50종 마스터 사조 (Neubrutalism, Bento Minimal, Y3K 등) 및 대표 3색 헥사코드 칩
- **감각 표현 직역 사전**: 자연어 프롬프트를 시각 코드로 변환
- **무결점 시스템 공식**: 8pt 그리드, 60-30-10 등 10대 엔지니어링 공식
- **Slop 방어 & 7대 상태**: 디자인 실패 방어 및 상태 머신
- **상업 실사 촬영 & 3D 비주얼**: 50종 마스터 카메라 화각 & 시네마틱 조명 기법
- **모바일 반응형 최적화**: 모바일 맞춤 슬림 하단 바구니 독 & 터치 최적화

## 💻 로컬에서 실행하기

저장소를 클론한 후 브라우저에서 `index.html` 파일을 더블 클릭하여 바로 실행할 수 있습니다:

```bash
git clone https://github.com/tmin2/vibe-taxonomy-studio.git
cd vibe-taxonomy-studio
# index.html 더블 클릭 또는 웹 서버 실행
```
