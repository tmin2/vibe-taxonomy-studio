# 🧩 VIBE TAXONOMY STUDIO

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://share.streamlit.io/deploy?repository=tmin2/vibe-taxonomy-studio&branch=main&mainModule=app.py)
[![GitHub Pages](https://img.shields.io/badge/GitHub%20Pages-Live%20Demo-blue?logo=github)](https://tmin2.github.io/vibe-taxonomy-studio/)

바이브 디자인 텍소노미 인터랙티브 스튜디오 (Vibe Taxonomy Studio) 웹 애플리케이션입니다.

- **UI 컴포넌트 전수**: 165종 전수 렌더링 & 원클릭 토큰 바구니 복사
- **AI & 물리 모션 피직스**: 38종 인터랙티브 라이브 애니메이션 (스켈레톤 쉬머, 다이내믹 아일랜드, 스프링 모핑 등)
- **글로벌 디자인 사조**: 50종 마스터 사조 (Neubrutalism, Bento Minimal, Y3K 등) 및 대표 3색 헥사코드 칩
- **감각 표현 직역 사전**: 자연어 프롬프트를 시각 코드로 변환
- **무결점 시스템 공식**: 8pt 그리드, 60-30-10 등 10대 엔지니어링 공식
- **Slop 방어 & 7대 상태**: 디자인 실패 방어 및 상태 머신
- **상업 실사 촬영 & 3D 비주얼**: 50종 마스터 카메라 화각 & 시네마틱 조명 기법

별도의 배포 대기 없이 지금 바로 브라우저에서 풀스크린으로 접속할 수 있습니다:

👉 **[https://tmin2.github.io/vibe-taxonomy-studio/](https://tmin2.github.io/vibe-taxonomy-studio/)**

---

### 2. Streamlit Cloud (원클릭 배포)
Streamlit Cloud 환경에서 실행하려면 아래 링크를 클릭하세요:

👉 **[Streamlit Cloud에서 원클릭 배포하기](https://share.streamlit.io/deploy?repository=tmin2/vibe-taxonomy-studio&branch=main&mainModule=app.py)**

1. 링크 접속 후 GitHub 계정으로 로그인합니다.
2. Repository(`tmin2/vibe-taxonomy-studio`), Branch(`main`), Main file path(`app.py`)가 자동으로 입력되어 있습니다.
3. 파란색 **[Deploy!]** 버튼만 누르면 약 1분 이내에 Streamlit 웹 앱이 완성됩니다.

---

### 3. 로컬에서 실행하기 (Local Run)

```bash
git clone https://github.com/tmin2/vibe-taxonomy-studio.git
cd vibe-taxonomy-studio
pip install -r requirements.txt
streamlit run app.py
```
또는 `index.html` 파일을 더블 클릭하여 웹 브라우저에서 바로 단독 실행할 수도 있습니다.
